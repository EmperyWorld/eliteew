# Справка по блокам маркетингового кабинета

Тексты лежат в **`blocks.ru.json`** и **`blocks.en.json`**. Язык выбирается по `i18n.language` (префикс `ru` → русский, иначе английский).

## Схема записи

Каждый ключ — это `helpBlockId`, который передаётся в `<SectionPanel helpBlockId="…" />` или `<MetricCard helpBlockId="…" />`.

```json
{
  "section.key": {
    "title": "Заголовок во всплывающей панели",
    "lead": "Одна строка: зачем блок",
    "paragraphs": ["Абзац 1", "Абзац 2"],
    "related": ["Связь с другим разделом", "…"],
    "tips": ["Практический совет", "…"]
  }
}
```

## UI

Кнопка с иконкой «i» открывает панель по **клику** (удобно и с клавиатуры, и на тач). Закрытие: крестик, клик снаружи, `Escape`.

При добавлении нового блока:

1. Добавьте объект в **оба** JSON с **одинаковым** ключом.
2. Укажите тот же ключ в `helpBlockId` у компонента.
