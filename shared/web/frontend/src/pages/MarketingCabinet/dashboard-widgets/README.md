# Виджеты интерактивного дашборда (Маркетинговый кабинет)

Краткая памятка для разработчиков: **реестр** (`registry.ts`) отдаёт определение виджета по `widget_key`; тело плитки — отдельные компоненты в `widgets/`. Поведение и волны работ описаны в плане эпика (ссылка ниже).

**`filters` / `sort` в `widget_config`:** парсятся в `parseWidgetConfig.ts` и для списковых плиток **отправляются на API**; бэкенд нормализует их при сохранении (`dashboard_widget_config.sanitize_widget_config`). Они **не меняют** ответ **`GET .../projects/{id}/dashboard`**: один проектный срез в `_build_project_bundle`, на клиенте список режется по `maxItems`. Политика и детали — `product/marketing/MARKETING-CABINET.md` (обзор / дашборд).

## UX (план §6, кратко)

1. **Анатомия плитки** — шапка с заголовком и при необходимости badge; **не** дублировать hide/lock/delete (они в правой колонке оболочки дашборда). Тело: `min-h-0 flex-1 overflow-y-auto`; для графиков задавать явную **min-height** (ориентир ~200px). Ссылка «во весь раздел» — визуально слабее, чем основные in-place действия.
2. **Плотность** — `compact`: меньше отступов, `text-xs`, по умолчанию меньше элементов; `comfortable`: текущий базовый стиль.
3. **Состояния** — loading / empty / error и обратная связь по мутациям; скелетон **внутри** плитки, а не вместо всей оболочки.
4. **Recharts** — `ResponsiveContainer`; оси и подписи читаемые; tooltip не обрезать; учитывать `prefers-reduced-motion`.
5. **Drag vs интерактив** — на контролах внутри плитки: `draggableCancel` и/или класс `.mc-dashboard-no-drag`, чтобы клики не таскали всю карточку.
6. **Доступность** — осмысленные `aria-label` / `title` через i18n; восстановление фокуса после модалок.

## Параллельные дорожки агентов (план §9)

Эпик разбит на фазы **W1–W5**; в пике параллельно выполняются разные todo с **непересекающимися файлами** (таблицы **§9.1–§9.3** в плане). Общие точки вроде реестра или `OverviewInteractiveDashboard` — после мержа или одной дорожкой (**W1-R**, **W1-O**, **W3-X** и т.д.), иначе отдать координатору. Краткий антиконфликтный промпт — **§9.6** плана.

## Дорожки финальной приёмки (план §12)
