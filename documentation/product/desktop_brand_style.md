# Desktop Brand Style

## Reference Surface

Эталонный visual reference для desktop UI: плавающий `DesktopWidget` в `web/frontend/src/pages/Desktop/DesktopWorkspaceContent.tsx`.

Это не просто один виджет. Это базовый язык для окон, правых панелей, popover-поверхностей и premium desktop shell в целом.

## Core Formula

1. Одна главная оболочка.
   Главная поверхность должна иметь один внешний контур. Нельзя делать вторую декоративную рамку поверх основной оболочки.

2. Glass-first surface.
   База строится на `var(--glass-bg)` / `var(--glass-bg-strong)` с `color-mix(...)`, а не на плоском непрозрачном фоне.

3. Accent wash сверху.
   У основной поверхности должен быть мягкий акцентный свет в верхней зоне: одна accent-radial и одна светлая radial-подсветка. Не делать 4-5 разноцветных пятен сразу.

4. Hairline и inner light.
   Основная поверхность использует тонкую рамку через `var(--glass-border)` и верхний световой hairline на 1px.

5. Compact premium density.
   Интерфейс должен быть плотным и дорогим, а не раздутым. Меньше лишних отступов, меньше пустых контейнеров, выше визуальная собранность.

## Geometry

- Внешний радиус основной поверхности: примерно `1.35rem` - `1.45rem`.
- Радиус внутренних секций: примерно `0.95rem` - `1.15rem`.
- Рамка: тонкая, светлая, полупрозрачная.
- Тени: глубокие, но чистые. Нужна глубина, а не грязное темное пятно.

## Surface Recipe

Для premium desktop surface использовать такой паттерн:

- `border border-white/10` + `borderColor: var(--glass-border)`
- фон на основе `color-mix(in srgb, var(--glass-bg-strong) ..., transparent ...)`
- 1 accent radial сверху
- 1 white radial сверху
- 1 soft overlay сверху вниз
- blur + slight saturate

Не делать:

- двойную внешнюю рамку
- тяжелый solid background без стеклянности
- толстую непрозрачную окантовку
- отдельный "пузырь" вокруг уже оформленного блока без смысловой причины

## Typography

- Базовый шрифт: `Manrope`
- Основной текст: белый или почти белый
- Вторичный текст: токены `--desktop-text-secondary` / `--desktop-text-muted` (в коде не использовать `slate-*` для нового UI)
- Микролейблы: uppercase, широкий tracking
- Крупные числовые значения: tighter tracking, аккуратная иерархия, без визуального шума

Desktop UI не должен выглядеть как enterprise-admin form. Он должен выглядеть как собранная premium OS surface.

## Inner Sections

Внутренние секции допустимы, но они обязаны быть тише основной оболочки.

Правило:

- outer shell = самый выразительный слой
- inner cards = мягче, тоньше, спокойнее

Если внутренняя карточка конкурирует с основной оболочкой по контрасту, свечению или толщине рамки, стиль сломан.

## Interaction Language

- Hover: мягкий, короткий, без агрессивных прыжков
- Lift: 1-2px, максимум
- Focus ring: чистый и заметный, но не кислотный
- Close / destructive actions: можно прятать до hover/focus, если это не ломает доступность
- Анимации: короткие spring / ease-out, без тяжелого "пружинного цирка"

## Window / Panel Translation

Когда этот стиль переносится на окна, панели или меню, нужно сохранять:

- одну основную оболочку
- glass background
- compact spacing
- тонкую световую границу
- мягкий верхний акцент
- спокойные внутренние секции

Нельзя переносить стиль как "рамка + еще одна рамка + еще один контейнер внутри".

## Do / Don't

### Do

- Использовать один сильный outer shell
- Делать внутренние блоки тише главной поверхности
- Собирать стили через общие пресеты и shared visual system
- Использовать accent glow дозированно

### Don't

- Делать двойной shell
- Оборачивать уже оформленную иконку/поверхность еще в один декоративный контейнер
- Использовать плоский белый dropdown на темной glass-поверхности
- Раздувать отступы и радиусы без причины

## Обои рабочего стола

Два сценария без конфликта: быстрый выбор из пресетов в настройках (компактный список) и расширенный **`WallpaperPicker`** (виртуализированная сетка 4×N превью, загрузка своего файла, история из БД). Оба пишут одно и то же значение в конфиг обоев; расширенный режим — когда нужен визуальный обзор и кастомное изображение.

**Layout-инвариант (2026-06-21):** ячейки сетки с **`DesktopChromeTooltip`** обязаны **`fullWidth`**, иначе styled **`TooltipV2`** (`inline-flex` trigger) схлопывает CSS Grid. Прокрутка — один контейнер внутри picker (`ModalAdvanced` **`contentClassName`** без второго scroll на body). Канон инцидента: [`DESKTOP-WINDOW-RUNTIME-PERFORMANCE.md`](desktop/DESKTOP-WINDOW-RUNTIME-PERFORMANCE.md) §2026-06-21 WallpaperPicker.
