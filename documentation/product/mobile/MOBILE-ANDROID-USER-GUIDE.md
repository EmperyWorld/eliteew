# Empery Mobile — руководство пользователя

**Обновлено:** 2026-06-02  
**Аудитория:** пользователи Android-приложения Empery Mobile (sideload / OTA)

## Установка и вход

1. Скачайте APK с [https://app.eliteew.ru/mobile-app/](https://app.eliteew.ru/mobile-app/) или обновитесь из приложения (см. ниже).
2. При первом запуске может потребоваться **доступ через периметр** (Yandex ID) — следуйте подсказкам на экране.
3. Нажмите **Войти** — откроется безопасный вход через Empery (Keycloak). Используйте тот же аккаунт, что и на сайте.

## Профиль

| Вкладка | Зачем |
|---------|--------|
| **Лента** | Новости EWDesk, посты команды |
| **Чат** | Переписка с друзьями, вложения, звонки |
| **Друзья** | Заявки, список друзей, профили |
| **UGS** | Генерация музыки и изображений, Desktop Hub |
| **Профиль** | Аватар, приватность, уведомления, обновления, **оформление** |

### Оформление

В **Профиль → Оформление** можно выбрать:

- **Яркость** — как в системе, светлая или тёмная (независимо от настроек Android).
- **Палитру** — системная, стеклянная, премиальная, изумруд или полночь.
- **Масштаб интерфейса** и **обои** — по желанию.

## Чат

- Откройте диалог из списка чатов.
- Введите сообщение и отправьте; непрочитанные отмечены счётчиком.
- Для **видеозвонка** используйте кнопку звонка в чате — откроется защищённый экран созвона.

## Друзья

- Примите или отклоните входящую заявку.
- Найдите человека по имени и отправьте заявку.
- Приглашение друга (реферальная ссылка) появится в будущих версиях — пока используйте поиск по имени.

## Генерации (UGS)

- В UGS Hub выберите инструмент (песня, изображение, AI-чат).
- Следуйте шагам мастера; генерация может занять несколько минут.
- История сохраняется в hub — можно воспроизвести или скачать результат.

## Уведомления

- Разрешите push при первом запросе (Android 13+).
- Настройте типы уведомлений в **Профиль → Уведомления**.
- Нажатие на уведомление открывает нужную вкладку (чат, друзья, лента).

## Обновления приложения

1. **Профиль → Обновления → Проверить**.
2. Если на сервере новее версия — нажмите скачать и установить.
3. При ошибке установки удалите старую версию и установите APK с сайта заново.

## Помощь

- Проблемы со входом: проверьте интернет и повторите вход.
- Нет доступа к серверу: возможен периметр — см. подсказку на экране доступа.
- **Диагностика для поддержки:** **Профиль → Поддержка → Диагностика для поддержки → Отправить в поддержку**. Отчёт уходит на сервер под вашей сессией Keycloak (без токенов в тексте). После отправки показывается номер обращения — сохраните его для связи с поддержкой. Альтернатива: **Поделиться** или **Копировать** и отправить вручную.
