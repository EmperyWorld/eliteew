# Ассистент: частые вопросы, поиск, вставить и спросить

Текст для базы знаний: боковая колонка FAQ, поиск по подсказкам, вставить в поле, кнопка «Спросить», «Показать в чате», обновить список, пустая база подсказок.

## Колонка «Частые вопросы»

В приложении **«Ассистент»** сбоку (или сверху на узком экране) — список **частых вопросов**, которые подготовил **администратор** организации. Рядом с заголовком может быть **число** — сколько подсказок загружено.

- **Раскрыть пункт** (стрелка) — показать **готовый ответ** администратора **без вызова ИИ**; удобно для коротких инструкций.
- **Клик по тексту вопроса** (подчёркивание при наведении) или **«Вставить в поле»** — переносит формулировку **в поле ввода** с **фокусом** для правки.
- **«Копировать ответ»** — готовый текст ответа FAQ **в буфер обмена** без добавления в чат (toast «Ответ скопирован»).
- **«Копировать вопрос»** — формулировку вопроса в буфер (toast «Вопрос скопирован»).
- **«Спросить»** — отправляет вопрос **сразу** помощнику (с учётом истории чата и документов на сервере).
- **«Показать в чате»** у готового ответа FAQ — добавляет пару «вопрос + ответ» **в область переписки** локально, **без запроса к модели**; чат **прокручивается к новому** сообщению внизу.

## Поиск по FAQ

Над списком — **поле поиска** («Поиск по вопросам и ответам…»):

- Фильтрует и **вопросы**, и **текст ответов**; совпадения **подсвечиваются**; строка **«Найдено: N из M»** показывает, сколько пунктов подошло.
- Клавиша **/** (слэш) на клавиатуре часто **переводит фокус** в это поле — быстрый поиск, не трогая мышь.
- **Escape** или кнопка **×** — **очистить** поиск.
- Если **ничего не найдено**, показывается подсказка **«Ничего не найдено — попробуйте другие слова»** и можно **сбросить поиск** одной кнопкой.
- При **нескольких** совпадениях — **«Развернуть все»** / **«Свернуть все»** под строкой «Найдено: N из M».
- Без активного поиска под полем — строка **«Клик по вопросу — вставить в поле · / — поиск»**.
- Если остался один подходящий пункт, он может **раскрыться автоматически**.

## Обновить список подсказок

Рядом с заголовком **«Частые вопросы»** — иконка **обновления**. Нажмите, если администратор недавно добавил записи, а у вас старый список. При ошибке загрузки — **«Повторить»**.

## Пустой список

Фраза вроде **«База подсказок пуста»** значит: администратор ещё **не добавил** FAQ — пишите **свободный вопрос** внизу или откройте **«Обращения»**.

## Популярные вопросы в пустом чате

Когда в чате ещё нет сообщений, в центре могут быть **чипы популярных вопросов** — быстрый старт: **один клик** показывает **готовый ответ администратора в переписке без ИИ** (как **«Показать в чате»**). Подробнее — отдельная статья про **chips и популярные вопросы**.

## Если не помогло

Вопросы **не про EliteEW** помощник не обязан разбирать — см. статью про границы тем Ассистента. Технический сбой или нет ответа — **«Обращения»** или кнопка **«Не помогло — в Обращения»** под ответом в чате.
