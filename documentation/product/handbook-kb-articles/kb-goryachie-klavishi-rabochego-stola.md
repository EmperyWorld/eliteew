# Горячие клавиши рабочего стола

Текст для базы знаний: какие сочетания клавиш в EliteEW, где посмотреть справку, Win+S, Alt+Tab, буфер обмена, поиск, настройки, виртуальные столы.

## Полная справка в приложении

Нажмите **F1** — открывается **справка по горячим клавишам** с актуальным списком для вашей версии рабочего стола. Там же может быть кнопка на **панели задач** с подсказкой **«Горячие клавиши»**.

Ниже — типовые сочетания, которые часто спрашивают; если что-то не срабатывает, ориентируйтесь на окно справки после **F1**.

## Рабочий стол и запуск

| Сочетание | Действие |
| --- | --- |
| **Ctrl+K**, **Win+K** или **⌘K** | Палитра команд (повтор — закрыть) |
| **Win+S** | Быстрый поиск |
| **Win+E** | Проводник (контент и файлы) |
| **Win+U** | Профиль пользователя |
| **Win+I** | Настройки рабочего стола |
| **Win+D** | Свернуть все окна |
| **Win+Ctrl+D** | Новый виртуальный стол |
| **Win+Ctrl+←** / **Win+Ctrl+→** | Предыдущий / следующий виртуальный стол |
| **Ctrl+Shift+N** или **Win+Shift+N** | Новая папка |
| **Win+V** | Буфер обмена (история) |
| **Win+1 … Win+9** | Закреплённые приложения на панели задач (порядок как на панели) |

## Окна и экран

| Сочетание | Действие |
| --- | --- |
| **Alt+Tab** / **Alt+Shift+Tab** | Переключение окон вперёд / назад |
| **Win+↑** / **Win+↓** | Развернуть / свернуть окно |
| **Win+←** / **Win+→** | Привязать окно влево / вправо |
| **Alt+F4** или **Alt+Escape** | Закрыть активное окно |
| **Win+Alt+S** | Снимок экрана |
| **Win+Shift+S** | Выделить область экрана |

## Тема и прочее

**Alt+Shift+T** переключает **светлую и тёмную тему** (в том числе при режиме «как в системе»). **Ctrl+Alt+Delete** открывает **диспетчер задач**, **Ctrl+Alt+L** — блокировка рабочего стола, **F5** — обновить рабочий стол.

На **Mac** клавиша **Win** в таблице соответствует **⌘ (Command)** там, где в справке это явно указано (например **⌘K** для палитры).

## Если не помогло

Сочетания могут перехватывать браузер или операционная система. Откройте **Обращения** и укажите **ОС**, **браузер** и какую клавишу нажимали. Полный список смотрите через **F1** на рабочем столе.
