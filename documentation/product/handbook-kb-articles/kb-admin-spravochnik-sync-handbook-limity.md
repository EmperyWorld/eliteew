# Админка Ассистента: sync handbook, dry-run и лимит файлов

Текст для базы знаний: оператор синхронизирует kb-*.md из git, dry-run без Postgres, лимит файлов 1–500, toast с лимитом, путь каталога.

## Где в админке

**Админка приложения** → раздел **«Ассистент»** → блок **документов KB**. Кнопки:

- **«Проверить sync (dry-run)»** — проверка без записи в БД и Qdrant;
- **«Синхронизировать kb-*.md из репозитория»** — полная синхронизация в фоне с индексацией; **без лимита** — диалог **подтверждения** (~106 статей); с заданным **«Лимит файлов»** — запуск сразу.

Поле **«Лимит файлов»** (1–500): пусто = **все** файлы; число **N** — первые N файлов. Кнопка **×** рядом с полем **сбрасывает** лимит. Под полем — подсказка и, после dry-run, **«· последний dry-run: N файлов»**.

## Dry-run

- Запрос сразу возвращает **`files`**, **`ok`**, **`fail`**, **`handbook_dir`**.
- **Postgres не нужен** — удобно проверить, что API видит каталог `kb-*.md` (bind на `.136` или baked образ на prod-core).
- Toast показывает результат и, если задан лимит, суффикс **«· лимит N»**.
- Под кнопками — строка **«Последний dry-run»** с числом файлов, лимитом (если был) и путём каталога; **«Копировать путь»** — в буфер.

## Полная синхронизация

- **Без лимита** — перед запуском **подтверждение** (все ~106 статей); если был **dry-run**, в диалоге показывается **последний путь и число файлов**.
- **С лимитом** — sync стартует сразу, в toast указан лимит.
- Ответ **202**, задача в фоне; toast **«Синхронизация … запущена»**.
- После sync документы проходят **indexing → indexed**; следите за summary **«проиндексировано / ошибки»**.
