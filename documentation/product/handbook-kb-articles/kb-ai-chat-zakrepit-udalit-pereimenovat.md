# AI Чат: закрепить, удалить и переименовать диалог

Текст для базы знаний: булавка на чате, удалить переписку, двойной щелчок по названию, пустой список.

## Закрепление

**Булавка** у чата в списке слева **закрепляет** его **вверху** списка — удобно для частых диалогов. Повторное нажатие **снимает** закрепление.

## Переименование

**Двойной щелчок** по **названию чата** (если поддерживается) открывает **переименование**. Имя помогает ориентироваться, когда чатов много.

## Удаление

Команда **«Удалить чат»** удаляет **текущую переписку** с сервера по правилам продукта. Операция может быть **необратимой** — подтверждайте осознанно. **Экспорт** в Markdown стоит сделать **до** удаления, если история важна.

## Пустой список

Если чатов нет, интерфейс предлагает нажать **«Новый»** и начать первый диалог.

## Если не помогло

Если удаление не проходит или чат **возвращается**, обновите страницу и повторите. Ошибка сервера — **Обращения**.
