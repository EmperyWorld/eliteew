# Конструктор сценариев (workflow) в UGS

Текст для базы знаний: конструктор workflow, воркфлоу, узлы, запуск сценария, сохранить перед запуском, только просмотр, права администратора UGS.

## Кто видит конструктор

**Конструктор** сценариев (workflow) в составе UGS доступен **администраторам UGS** — обычным пользователям открывается **Хаб** и связанные разделы без редактирования графа. Если вкладки **«Дашборд»**, **«Админ»** или **«Конструктор»** не появляются, у учётной записи, скорее всего, нет нужных прав.

## Что такое воркфлоу

**Воркфлоу** — это **схема из узлов и связей**: данные проходят по цепочке и выполняют шаги генерации или обработки. У сценария есть **имя** и **описание**; перед **запуском** его нужно **сохранить** — иначе интерфейс напомнит: сначала сохранение, потом выполнение.

## Готовые сценарии из каталога

Если открыт **каталоговый** сценарий, в старом конструкторе он может быть **только для просмотра** — редактировать такой граф нельзя, можно изучить и запустить по правилам среды.

## Запуск

Перед стартом иногда нужно **заполнить входные значения** для узлов ввода. После запуска отображаются **статус**, **прогресс** и **результат**; пустой экран до запуска — норма: сначала нажмите выполнение сценария.

## Если не помогло

Сообщение **«нет прав на сохранение»** означает ограничение роли — обратитесь к **администратору UGS**. Ошибки проверки сценария (**«не удалось проверить»**) снимите скриншотом и отправьте в **Обращения**.
