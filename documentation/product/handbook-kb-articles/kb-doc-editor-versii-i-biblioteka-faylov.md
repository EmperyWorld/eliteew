# Doc Editor: версии документа и библиотека файлов

Текст для базы знаний: история версий, восстановить версию, открыть из библиотеки, импорт, распознавание текста с картинок.

## История версий

В редакторе может быть панель **«История версий»**: список **снимков** документа. Выберите запись, чтобы **просмотреть** содержимое прошлого состояния. **«Восстановить эту версию»** возвращает документ к выбранному снимку; текущее содержимое при этом обычно **сохраняется как новая версия** — вам покажут подтверждение с пояснением.

Если версии не загрузились, используйте **повтор** или проверьте сеть.

## Открыть из библиотеки

**«Открыть из библиотеки»** позволяет взять файл из **единого хранилища контента** EliteEW. На один раз обычно можно выбрать **один** файл ограниченного размера; допустимые форматы перечислены в подсказке (документы, PDF, текст, изображения и др.). Новые файлы можно **перетащить** в редактор или воспользоваться **импортом**.

## Импорт и распознавание

При **импорте** списка файлов сверху может отображаться **прогресс**. Для изображений с текстом доступно **распознавание** — его можно **отменить** пакетом, если операция ещё идёт.

## Если не помогло

Укажите в **Обращениях**, не открывается ли библиотека или падает ли **восстановление версии** с текстом ошибки.
