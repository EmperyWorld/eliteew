# Мессенджер: переписка, удаление сообщений и чата

Текст для базы знаний: «как удалить переписку в GAF», «как удалить сообщение в чате», «Мессенджер», «личные чаты», «убрать у себя», «удалить для всех», «правый клик по сообщению», «скопировать текст чата», «контекстное меню GAF», «ПКМ по чату», «закрепить диалог».

## Что такое Мессенджер

**Мессенджер** (на рабочем столе может отображаться как **Мессенджер**) — приложение для **личных чатов один на один** с друзьями: переписка, история, вложения, уведомления. Откройте его **двойным щелчком** по значку на рабочем столе или через меню «Пуск», если значок закреплён. Категория в магазине часто **«коммуникации»**.

## Контекстное меню по сообщению (правый клик)

По **правому щелчку** по строке сообщения (по пузырю и области вокруг него в этой строке) открывается **меню действий** — те же возможности, что и у кнопки **с тремя точками** у сообщения, плюс быстро **скопировать текст** и при необходимости **ответить** на сообщение.

Типичные пункты: **копировать**, **ответить**, при вашем сообщении с текстом — **изменить**; **убрать у меня** и при необходимости **удалить для всех** — по тем же правилам, что и в меню «⋯».

Если открыто меню, можно пользоваться **клавиатурой**: стрелки вверх и вниз по пунктам, в начало и в конец списка — как принято в меню рабочего стола, **Esc** — закрыть без действия.

**Долгое нажатие левой кнопкой** по пузырю сообщения по-прежнему **копирует текст** в буфер **без** открытия меню — удобно, когда нужен только текст.

Синонимы: контекстное меню сообщения, ПКМ по сообщению, скопировать сообщение в GAF, меню как у трёх точек.

## Контекстное меню в списке чатов

По **правому щелчку** по строке чата в списке слева можно **открыть чат** или **закрепить / снять закреп** — без лишних шагов, если привычнее меню, чем кнопки в строке.

## Удалить одно сообщение (не весь чат)

1. Откройте нужный диалог в списке слева.
2. Найдите **сообщение** в ленте.
3. Либо нажмите кнопку **с тремя точками** (меню действий с сообщением) — подсказка вроде «Действия с сообщением», либо откройте то же меню **правым щелчком** по сообщению (см. выше).
4. Доступно:
   - **«Убрать у меня»** — сообщение исчезнет **только у вас** на ваших устройствах; у собеседника переписка может **не измениться**.
   - **«Удалить для всех»** — доступно **автору** сообщения; у **обоих** сообщение будет помечено как удалённое; **отменить** для тех, кто уже прочитал, **нельзя**.

Подтверждение в диалоге объясняет последствия — нужно согласиться, чтобы действие выполнилось.

Синонимы запроса пользователя: стереть сообщение, удалить сообщение в GAF, убрать сообщение только у себя, удалить для собеседника.

## Очистить историю чата только у себя (не удаляя чат целиком)

В шапке открытого чата есть кнопка **«Ещё»** (иконка с тремя горизонтальными точками) — меню **«Действия с чатом»**.

- Пункт **«Очистить историю»** — история этого чата удаляется **только у вас**; у собеседника сообщения **остаются**.

## Архивировать чат

В том же меню **«Действия с чатом»** есть **«Архивировать чат»** — чат убирается из основного списка по правилам интерфейса (подтверждение показывается отдельно).

## Удалить чат для обоих участников

В меню **«Действия с чатом»** есть опция **«Удалить для обоих»** (на узком экране может быть короткая подпись **«Удалить»**). Это **необратимо** удаляет чат и **всю историю** для **обоих** участников. Перед удалением показывается предупреждение — нужно подтвердить.

Не путать: **удалить одно сообщение** (меню на пузыре) и **удалить весь чат** (меню «Ещё» в шапке диалога).

## Поиск по переписке

В чате может быть **поиск по тексту** в текущем треде (поле поиска в панели над лентой) — удобно найти старое сообщение без прокрутки всей истории.

## Если что-то не работает

Проверьте сеть. При ошибках отправки может появиться отдельное сообщение (в том числе при **слишком частых** запросах — подождите и повторите).

## Вложения и Файловый менеджер

Файл, отправленный **вложением** в GAF, может появиться у получателя в **Файловый менеджер**. Чтобы **скрыть его только у себя**, не удаляя у отправителя, откройте Файловый менеджер и используйте **«Убрать»** (не «Удалить»).
