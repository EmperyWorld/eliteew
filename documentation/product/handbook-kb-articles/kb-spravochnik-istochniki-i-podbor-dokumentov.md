# Ассистент: источники ответа и подбор по документам

Текст для базы знаний: источники справочника в конце ответа, подбираю по документам, откуда взялся ответ, RAG, база знаний организации, готовый ответ FAQ без источников.

## Два вида ответов

| Вид | Как получить | Источники внизу |
|-----|--------------|-----------------|
| **Готовый FAQ** | Chip, **«Показать в чате»**, раскрытый пункт слева | Обычно **нет** — это текст администратора |
| **Ответ модели** | **«Спросить»**, свой вопрос в поле ввода | Может быть блок **«Источники справочника»** |

У готового FAQ в чате может быть подпись вроде **«Готовый ответ из частых вопросов»** — это **не** генерация ИИ по документам.

## Пока ответ готовится (модель)

После отправки вопроса модели:

- Сначала **«Ответ… (N с)»** — идёт поток текста.
- Может появиться строка **«Подбираю по документам: …»** с **названиями** материалов — сервер **ищет фрагменты** в базе знаний вашей организации **до** или **во время** сборки ответа.
- Это **не** поиск в интернете — только **загруженные тексты** администратора (статьи `kb-*.md` и другие документы KB).

## Блок «Источники справочника»

В **конце** длинного ответа модели часто есть строка:

**«Источники справочника:»** «Название документа 1»; «Название 2» …

- Это **названия документов KB**, по которым собран ответ.
- Если документов много, может быть **(+N ещё)** — показаны не все.
- **Не** нажимайте на них как на ссылки для открытия приложений — для запуска программ используйте **ссылки в основном тексте** ответа (см. статью про **ссылки в ответе**).

## Если источников нет

- Вопрос закрыт **только FAQ** из промпта — источники могут не показываться.
- RAG **выключен** администратором — ответ только из общих инструкций и FAQ.
- Модель **не нашла** подходящих фрагментов — помощник может сказать, что не знает, и предложить **«Обращения»**.

## Чем не путать

| Термин | Смысл |
|--------|--------|
| **Источники справочника** | Документы KB организации для **этого** ответа |
| **Частые вопросы** | Готовые пары администратора **без** подбора по KB в момент клика |
| **Обращения** | Ваш запрос команде продукта, не список документов |

## Связанные темы

- **Ссылки в ответе** — открыть приложение одним кликом.
- **Интерфейс чата** — стоп, экспорт, «Помогло».
- **Популярные вопросы (chips)** — ответ без модели и без источников.
