# Редактор документов: структура текста, формат и совместная работа

Статья для базы знаний **Ассистента** (ассистент на рабочем столе). Вопросы пользователей: почему документ «в одну строку», как сохранить заголовки и списки, как подключиться к совместному редактированию, кто может отключить участника.

## Структура документа и абзацы

- Текст в редакторе состоит из **блоков**: заголовки, абзацы, списки, цитаты. Это важно для нумерации строк, экспорта в другие форматы и для совместной работы.
- Если документ раньше открывался как **один длинный абзац** (всё слитно), при обновлении приложения система может **восстановить** привычную структуру: заголовки, маркеры списков, отдельные абзацы — в том числе для документов в формате **Markdown** и для старых записей в одном блоке.
- **Markdown**-документы при открытии превращаются в обычное поле редактора с заголовками и списками, а не в «простыню» без переносов.

## Формат Markdown в интерфейсе

- Режим **«Исходник Markdown»** показывает текст с разметкой; выход из режима переводит разметку обратно в оформленный текст. При **включённой совместной сессии** переключение в режим Markdown может быть недоступно — нужен общий визуальный редактор для всех участников.

## Совместная работа

- **Подключиться** — в шапке редактора; без этого вы редактируете документ сами, без синхронизации с другими.
- **Пригласить друга** по документу можно **после** того, как вы нажали «Подключиться» к сессии: иначе кнопка приглашения неактивна и подсказывает сначала подключиться.
- В списке **«Сейчас в документе»** отображаются **имена** участников (без адреса почты). У каждого видно, в какой части документа он сейчас работает.
- **Владелец файла** может **отключить** участника от совместного редактирования. Если **владелец** выходит из сессии, совместная работа по этому документу завершается для всех подключённых.
- При **переключении на другой документ** или вкладку с активной сессией система **предупреждает** и отключает совместное редактирование для предыдущего документа.

## Если что-то не так

- Не сохраняется, не открывается, «пропал» текст — опишите в **Обращениях**, откуда открывали файл и что делали перед этим.
- Более общий обзор редактора: статья **«Doc Editor: документы на рабочем столе»** (`kb-doc-editor.md`).
