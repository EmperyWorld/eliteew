# Уведомления: прочитать, очистить и группы

Текст для базы знаний: отметить прочитанным, прочитать все, очистить все, типы уведомлений информация успех предупреждение ошибка, **группировка по источнику**, **раскрыть секцию**, **прочитать группу**.

## Прочитанные и непрочитанные

В центре уведомлений можно включить показ **только непрочитанных** или **всех**. Счётчик у колокольчика на панели задач часто показывает число **непрочитанных**; при очень большом числе может отображаться сокращение вроде **«99+»**.

## Массовые действия

Обычно доступны кнопки:

- **«Прочитать все»** — снять непрочитанность со всего списка;
- **«Очистить все»** — удалить все записи из истории; перед этим обычно показывается **запрос подтверждения**, чтобы не удалить случайно;
- в **полном окне** может быть **экспорт в файл** (например JSON) для сохранения списка у себя.

Если кнопка неактивна, возможно, включён **фильтр**, при котором нечего отмечать, или список уже пуст.

## Группы по типу

В полном окне уведомления можно смотреть **блоками по типу**: **информация**, **успех**, **предупреждения**, **ошибки** — так проще найти важное. В каждой группе может быть кнопка **«Прочитать»** только для этой группы.

## Группы по источнику

В **полном окне** можно переключить режим: группировать не по типу, а **по источнику** (откуда пришло событие). Тогда список разбит на **секции**, которые можно **раскрывать и сворачивать**. У каждой секции может быть своя кнопка **«Прочитать»** для всех уведомлений **в этой группе**. Если список **очень длинный** и включён **упрощённый прокручиваемый режим**, группировка по источнику может быть **недоступна** — остаётся только группировка по типу.

## Связь с настройками звука

Режим **«Не беспокоить»** и **тема звука** настраиваются в **быстрых настройках** центра уведомлений — см. отдельную статью про звук.

## Если не помогло

Если после **«Прочитать все»** счётчик не обнуляется, обновите страницу или опишите шаги в **Обращениях**.
