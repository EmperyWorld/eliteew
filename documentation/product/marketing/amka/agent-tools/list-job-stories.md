# Инструмент · `list_job_stories`

## Назначение

Вернуть **краткий обзор Job Stories (JTBD)** проекта: заголовок, формулировка задачи, опционально баллы важности/возможности — для вопросов про потребности, приоритеты и формулировки jobs.

## Исходный код

- Схема Llama: опциональный **`limit`** (integer), описание «1–12, по умолчанию 8».
- Исполнитель: **`_tool_list_job_stories`** в `marketing_agent_tools.py`.

## Параметры

| Поле | По умолчанию | Кламп |
|------|----------------|--------|
| `limit` | 8 | `max(1, min(12, int(limit)))`; при ошибке приведения типа — 8 |

## SQL

```text
SELECT title, statement, importance_score, opportunity_score
FROM job_stories
WHERE project_id = $1 AND deleted_at IS NULL
ORDER BY updated_at DESC NULLS LAST, created_at DESC
LIMIT $2
```

## Форматирование ответа

- Префикс: **`Job Stories (кратко):`**
- Каждая карточка: нумерация, **жирный** `title`, опционально `[важность=…, возможность=…]`, перенос, `statement` усечённый до **420** символов + «…».

## Пустой результат

Строка: *«В проекте пока нет Job Stories.»*
