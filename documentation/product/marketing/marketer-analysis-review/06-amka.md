# AMKA: аудит и прогон по маркетинговому кабинету

## Что это для маркетолога

**AMKA** — сценарий **прохода по разделам** маркетингового кабинета с **аудитом и исполнением шагов** по правилам продукта: строится план, вы подтверждаете или корректируете ход, фиксируются отчёты по этапам. Это ближе к **операционному контролю заполненности и качества кабинета**, чем к одному текстовому отчёту «о рынке».

Это **не** окно помощи на рабочем столе (EWA / спутник): только вкладка AMKA внутри маркетингового кабинета.

## На что смотреть при проверке

1. **Соответствие этапов** вашему пониманию процесса (JTBD, доказательства, сегменты и т.д.).
2. **Отчёты по шагам** — есть ли конкретика, а не только «всё хорошо».
3. **Именованные сценарии (пресеты)** в конструкторе — если их включили, убедитесь, что **дополнительные задачи** действительно нужны проекту (лишние шаги увеличивают время).

## Чего AMKA не делает

- Не заменяет **полевое исследование**.
- Не гарантирует **методологическую полноту** вне тех правил, которые заложены в продукте — ваш методолог всё равно должен **подписаться** под итогом для заказчика.

## Чек-лист

- [ ] Перед запуском понятен **режим** (автоматический vs по шагам), чтобы команда не потеряла контроль.
- [ ] После прогона **просмотрены** ключевые отчёты по разделам.
- [ ] Решение о **пресете** согласовано с руководителем проекта.
