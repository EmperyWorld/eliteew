# Проверка анализов в маркетинговом кабинете (для маркетолога)

Эти файлы помогают **самостоятельно оценить**, насколько результат анализа пригоден для решений: что система реально учитывает, чего ждать от отчёта и когда нужна доработка человеком.

**Для кого:** руководитель проекта, маркетолог, методолог — не обязательно знать устройство системы.

**Как пользоваться:** начните с [00-obshie-principy.md](00-obshie-principy.md), затем откройте раздел по нужному инструменту. В конце — [08-svodnaya-tablica.md](08-svodnaya-tablica.md): «что выбрать для какой задачи».

**Важно:** большинство сценариев опираются на **данные, которые уже есть в проекте** (карточка проекта, загруженные документы, заполненные разделы). Это **не замена** живому интернет-исследованию и **не гарантия** актуальности рынка, если в проект не загружены свежие материалы.

Технический канон для ИТ: [../README.md](../README.md) (ИМК — [../IMC-MISO-ARCHITECTURE.md](../IMC-MISO-ARCHITECTURE.md), AMKA — [../AMKA-REFERENCE.md](../AMKA-REFERENCE.md)).
