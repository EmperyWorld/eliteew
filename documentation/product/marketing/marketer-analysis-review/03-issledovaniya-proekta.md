# Исследования проекта (классический список по типу)

## Что это

Отдельная сущность в кабинете: **исследование с типом** (рынок, конкуренция, продукт, риски, кастом и т.д.) и **запросом/вопросом**. Запуск генерирует **текстовый ответ** на основе контекста проекта и поиска по загруженным материалам — по смыслу близко к «одному большому промпту», но с **историей запусков** и статусом.

## Отличие от ИМК

- **ИМК** — каталог **именованных сценариев** (готовая структура отчёта под тип).
- **Исследования проекта** — **ваш тип и ваш формулировка запроса** в рамках списка типов.

Для проверки качества действуют те же правила: **наполнение проекта**, **ясный запрос**, **вычитка результата**.

## Как проверить результат

1. Ответ **отвечает на формулировку запроса**, а не на соседнюю тему.
2. Нет **голословных выводов** там, где в материалах нет опоры (или явно сказано, что данных мало).
3. При необходимости — **второй запуск** с уточнённым запросом или после догрузки файлов.

## Чек-лист

- [ ] Тип исследования **совпадает** с тем, что нужно команде (не «custom» без описания, если важна методология).
- [ ] В запросе **нет двусмысленности** (одна главная цель).
- [ ] Результат **сохранён/зафиксирован** там, где у вас принято вести знания проекта.
