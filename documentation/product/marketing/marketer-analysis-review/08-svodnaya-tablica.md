# Сводная таблица: какой инструмент для какой задачи

Используйте как **быстрый ориентир**; детали — в отдельных файлах этой папки.

| Задача маркетолога | Что открыть в кабинете | На что опирается результат |
|--------------------|-------------------------|------------------------------|
| Готовый отчёт по сценарию (SWOT, JTBD, тренды, конкуренция, глубокое исследование…) | **ИМК** | Проект, документы, ваш бриф/файлы по правилам сценария |
| SWOT как **таблица факторов** с ручным редактированием | **Анализ → SWOT** | То же + структура кабинета; можно генерировать и править |
| Свой вопрос «в свободной форме» с типом исследования | **Исследования проекта** | Проект, документы, текст запроса |
| Черновик **job stories** из текста | **JTBD → извлечение** | Ваш текст/материалы и контекст проекта |
| Быстрый текст, идеи, перефраз | **AI Studio** | Запрос + при необходимости проект |
| Диалог, уточнения в несколько заходов | **Контекстный чат** | Проект или компания + история беседы |
| Пройти кабинет **по регламенту**, отчёты по разделам | **AMKA** | Правила продукта + ваши данные в разделах |
| Заполнить **документ/поля** из файла или проекта | **Автозаполнение** | Выбранный источник и настройки сценария |

## Если результаты разных инструментов расходятся

Это **нормально**, если:

- разные **входы** (один запуск без файлов, другой с догрузкой);
- разные **форматы** (структурированный SWOT vs текстовый отчёт ИМК).

**Что делать:** выбрать **один основной артефакт** для решения, второй использовать как идеи; при необходимости **синхронизировать** формулировки вручную и зафиксировать в проекте.

## Минимальный набор для «уверенного» анализа

1. Проект **наполнен** документами и ключевыми полями.  
2. Один **основной инструмент** под задачу (не пять параллельно без выбора).  
3. **Вычитка человеком** перед внешним использованием.
