# UI screenshots — контур и слоты

**Статус:** матрица locked · **кадры отложены** (оператор: текстовый черновик без скринов; волна Ws позже)  
**Назначение:** UI truth для обзорного пакета под сценарий **передачи / внедрения контура** (не mass SaaS demo).

## Доступ для агента (приоритет)

| Способ | Рекомендация |
|--------|----------------|
| **1. Браузер уже открыт** (оператор залогинен в scrubbed demo) | **Предпочтительно** — пароль/токен в чат не нужны |
| **2. Короткоживущий токен / magic link** | Если нужен вход агенту; не класть в MD/export |
| **3. Логин+пароль в чат** | **Избегать**; только одноразовый demo-аккаунт и сразу ротация |

Секреты съёмки **не** пишутся в `product-overview/` и не попадают в share zip.

## Контур съёмки (рекомендованный)

| Параметр | Выбор |
|----------|--------|
| Среда | Scrubbed **demo-тенант** на Desktop shell EliteEW (не живой prod с чужими данными) |
| Хост | Хост — один прогон; в подписи кадра указать класс хоста без имени вендора |
| Данные | Вымышленный холдинг / проекты / ФИО; без реальных клиентов и лиц |
| URL / chrome | Скрыть или scrub адресную строку; без LAN IP, портов, client id IdP |
| Бренд в кадре | Допустимы EmperyWorld / нейтральный demo-орг; свой бренд поверх продукта — отдельный кадр только если готов |

Запрещено в кадре: ops CLI, stack names как offer, реальные сотрудники, «аттестовано», VR model name.
