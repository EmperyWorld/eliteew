# P10b — Live carrier and sealed install

## Thesis

| Carrier | Meaning | Honest status |
|---------|---------|---------------|
| **Sealed capsule / seat** | Access file to a place (P9a) | Current access-issue path for the desktop client |
| **Live USB / metal install** | Boot media → install a sealed OS carrier (Trusted Substrate) | Development target contour; a mass sealed image at every organization is not claimed |
| **Persistent install** | Kiosk-class OS + EliteEW payload | Target end-state; bootstrap payload may differ from the final Tauri |

**Not promised:** live USB = ready air-gap with no channel · Substrate replaces Connection Agent · “already fully replaced Fedora kiosk at Empery.”
