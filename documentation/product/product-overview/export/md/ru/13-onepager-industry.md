# Обзор для внедрения / отрасли

Для руководителя внедрения и тех, кто поднимает контур у организации.

## В одном абзаце

EliteEW — **рабочая среда** и **дар миру** по MIT: организация принимает
код, разворачивает свой экземпляр силами ИТ/SI и живёт в своём контуре.
Сопровождение (если нужно) — опция, не замена дара сопровождением. Структура затрат
self-host — ориентир по ФОТ/хосту, не тариф на код
([P3d](03d-tco-orientative.md) · [P3e](03e-delivery-models.md)).
