# P5 — Приложения, магазин, два контура ИИ

## Магазин приложений

На столе есть **магазин**: каталог, установка/удаление под доступ организации, карточка приложения. Состав стола собирается под роль — не один фиксированный набор иконок у всех.

**Флот / App Store** в смысле «витрина + установленное» — живой сценарий desktop shell. Не путать с магазинами ОС (магазин хост-ОС / магазин хост-пакетов).

## Два ИИ-контура — не смешивать

| Контур | Имя в UI | Суть | Не путать с |
|-----|------|-----|---------|
| **EWA** | Ассистент / спутник | Присутствие и действия на столе, оркестрация | Экспертами |
| **Experts** | Эксперты / чат с ИИ | Инструментальный чат с файлами и «командой» | Спутником EWA |

**Есть:** это разные продукты на столе. **Не обещаем:** «один ИИ делает всё одинаково».

Сравнение «хост / DIY / EliteEW» — кратко в [P1](01-what-is-eliteew.md); границы обещаний — [P12](12-honest-limits.md).
