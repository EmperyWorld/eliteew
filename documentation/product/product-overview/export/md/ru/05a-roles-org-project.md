# P5a — Роли организации и проекта

**Exemplar:** маркетинговый кабинет + файлы проекта

## Модель (обзорный язык)

| Роль | Смысл | Типовые полномочия |
|------|--------|-------------------|
| **Собственник / владелец контура компании** | Задаёт рамку организации | Компания, высокий уровень доступа к проектам |
| **Руководитель проекта** | Ведёт конкретный проект (`created_by` / лид) | Команда, модули, удаление чувствительных записей, настройки |
| **Участник** | Работает в выданных модулях | Только явные права на разделы; пустой список прав ≠ полный write |

Дополнительно: право загрузки в **vault проекта** может выдаваться отдельно и **не** открывает все модули кабинета само по себе.

Приглашение в команду проекта — под контролем руководителя; серверные проверки доступа обязательны (не «все видят всё»).
