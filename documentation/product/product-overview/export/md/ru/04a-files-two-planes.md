# P4a — Файлы: метаданные, object store, доступ, поиск

**Схема:** [D05](../assets/diagrams/D05-files-two-planes.md)

## Две плоскости (честно)

| Плоскость | Что хранит | Смысл для пользователя |
|-----------|------------|-------------|
| **PostgreSQL** | Метаданные, версии, ACL, привязка к компании/проекту | «Кто видит файл и в каком проекте он лежит» |
| **Object store (S3-класс; в контуре Empery — SeaweedFS)** | Байты файла | Содержимое не лежит «просто на диске ПК сотрудника» как единственный источник истины |

Пользователь работает через **Файловый менеджер**; в PG/Seaweed руками не ходит.

## Что умеет контур

- Единая библиотека с папками, версиями, шарингом, квотой хранилища  
- Скоуп **компании / проекта** (в т.ч. vault проекта маркетинга)  
- Поиск: по тексту и **умный** (полнотекст + семантика по индексу документов)  
- После извлечения текста / OCR сканов — материал становится находимым в поиске (обработка на стороне платформы; не «магия 100% на любом скане»)
