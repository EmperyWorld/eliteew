# P10a — Нативный клиент и гибрид

Поставка — не «только браузер» и не «только контейнеры»:

- **Браузерный** рабочий слой (cloud / on-prem)
- **Нативные** клиенты (Connected / FoFline / offline-capable seats) на открытой серверной ОС и на обычной десктоп-ОС
- Контейнерный runtime на стороне платформы — для сервисов, **не** как единственный способ открыть стол пользователю

Гибрид: хост остаётся своим; EliteEW — управляемый слой поверх него ([P1](01-what-is-eliteew.md)).
