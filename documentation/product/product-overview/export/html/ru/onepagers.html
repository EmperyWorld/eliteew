Обзор: дар миру и свой контур

Короткая страница для тех, кто решает, принимать ли EliteEW в организацию
как открытый рабочий комплекс.

Что это

EliteEW = рабочий стол организации (приложения, файлы, проекты, ИИ на своих данных)
+ закрытый рабочий слой (личное и рабочее разделены)
+ first-party код как дар миру по MIT.

Не замена хост-ОС. Не «100% защита». Не аттестат. Не «принятие дара закрепляет штат авторов навсегда».

Формула — P1; лицензия и условия лицензии — P3c;
границы — P12.

Четыре вопроса

Вопрос Ответ Куда
Что отдано миру? First-party код: запуск, изучение, изменение, распространение по MIT; сохранение copyright и текста разрешения P3c
Что не входит в дар? Штат авторов, SLA, официальный бренд, чужие секреты P3e · P12

Обзор для ИБ / периметр

Сжатый вход. Полный путь: P2 → P2a → P7d → P9a → P8a → P8 → P7c → P12 → P3.

В одном абзаце

EliteEW добавляет рабочий слой поверх личного устройства: файлы и приложения организации — в контуре, без системного агента на личной ОС как нормы. Снаружи — закрытый периметр и доступ по выданному доверию. У нативных Connected/FoFline-клиентов доступ завязан на личность, сервисный entitlement, канал и устройство (не универсально для всего браузера). Сквозное шифрование чата — по согласию, с ключом на телефоне. Нормативная карта — «помогает контуру», не аттестат. Поставка — P3e.

Обзор для внедрения / отрасли

Для руководителя внедрения и тех, кто поднимает контур у организации.

В одном абзаце

EliteEW — рабочая среда и дар миру по MIT: организация принимает
код, разворачивает свой экземпляр силами ИТ/SI и живёт в своём контуре.
Сопровождение (если нужно) — опция, не замена дара сопровождением. Структура затрат
self-host — ориентир по ФОТ/хосту, не тариф на код
(P3d · P3e).

Дар и лицензия

Вопрос Ответ
Лицензия first-party кода? MIT (корневой LICENSE); не весь monorepo одной лицензией
Что свободно? Запуск, изучение, изменение, распространение на условиях MIT
Сетевая модификация? MIT не требует публикации исходников сервиса
Third-party / MIT-исключения? По своим лицензиям; карта + SBOM / NOTICE
Бренд EliteEW? Не передаётся MIT
Штат авторов / SLA в «даре»? Нет; сопровождение — отдельная опция
Тарифы услуг в этом пакете? Нет — пакет не содержит тарифов
