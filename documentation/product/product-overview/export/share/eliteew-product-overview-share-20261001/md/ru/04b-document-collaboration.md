# P4b — Совместная правка документов

## Тезис

В **редакторе документов** доступна совместная работа: присутствие участников,
курсоры, синхронизация правок. Подключение к совместной сессии — **явное**
(пользователь включает «Подключиться»), не скрытый фоновый режим.

Приглашать в совместную работу может **владелец документа**. Есть комментарии /
review в рамках редактора.

## Честная рамка

| | |
|--|--|
| **Есть** | Присутствие · курсоры · синхрон внутри редактора продукта · приглашает владелец |
| **Не обещаем** | Паритет со всеми внешними совместными редакторами · совместная правка любого бинарного офис-формата без конвертации |
