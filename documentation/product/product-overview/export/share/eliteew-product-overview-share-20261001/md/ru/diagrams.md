# D01 — Hybrid formula (P1)

```mermaid
flowchart LR
  subgraph Host["Хост-устройство"]
    OS["Десктоп / серверная ОС / VR-браузер"]
  end
  subgraph Elite["Рабочий слой EliteEW"]
    Desk["Стол + apps + файлы"]
    Sec["Периметр + роли + доступы"]
  end
  OS --> Elite
  Desk --- Sec
```

**Смысл:** EliteEW — управляемый слой поверх устройства, не «выбросили ядро ОС».

# D07 — Atomic access (P8a)

```mermaid
flowchart TB
  I["Личность"] --> AND{"Все истины?"}
  L["Лицензия активна"] --> AND
  C["Канал разрешён"] --> AND
  D["Устройство / ключ"] --> AND
  B["Привязка учётки"] --> AND
  AND -->|да| OK["Доступ в продукт"]
  AND -->|нет| DENY["Отказ · без детального оракула"]
```

**Смысл:** native Connected / FoFline — связка факторов; не универсально для любого браузерного входа.
**Alt:** Условный доступ как логическое И, не один пароль.

# D11 — Дар миру: MIT и опциональное сопровождение (P3e)

```mermaid
flowchart LR
  Gift["Дар миру · MIT first-party"]
  Gift --> Run["Запуск / изучение / изменение"]
  Gift --> Share["Распространение по MIT"]
  Gift --> Net["Модифицированный сетевой сервис → source своим users"]
  Run --> Org["Свой контур организации"]
  Share --> Org
  Help["Опциональное сопровождение"]
  Help --> Accept["Помощь с приёмкой / SBOM"]
  Help --> Ops["Помощь с эксплуатацией"]
  Accept --> Org
  Ops --> Org
```

**Смысл:** центр — свободный код как дар. Сопровождение (если есть) помогает
принять и крутить контур, но **не** подменяет и не закрывает исходники.

# D12 — Принять дар у себя (P3f)

```mermaid
flowchart TB
  Source["MIT source · commit/tag"]
  Source --> Check["Сверка артефактов"]
  Check --> Build["Сборка / стенд"]
  Check --> Docs["Docs + SBOM / NOTICE"]
  Build --> Pilot["Пилот орг. единицы"]
  Pilot --> Scale["Масштаб у своей службы"]
  Help["Опциональное сопровождение"] -.-> Check
  Help -.-> Pilot
```

**Смысл:** исходники открыты по MIT; приёмка у себя сверяет версию, сборку,
документацию и границы. Чужие prod-секреты в «дар» не входят.
