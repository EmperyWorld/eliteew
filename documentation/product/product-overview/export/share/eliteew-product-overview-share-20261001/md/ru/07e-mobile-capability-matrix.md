# P7e — Mobile capability matrix

## Есть на Android-спутнике

| Возможность | Примечание |
|-------------|-----------|
| Лента / EWDesk | Спутник |
| Мессенджер GAF | В т.ч. путь к E2EE при trusted (P7c) |
| Друзья / профиль | Да |
| Уведомления / push | Да (с политиками категорий) |
| Часть UGS (чат, картинки, песни, презентации) | Подмножество |
| Видеозвонки (WebView Meet) | Да; учитывает настройку «куда принимать звонок» |
| Упрощённый пульт стола | Да |
| Trusted device / Secure Connection | Опциональный слой безопасности |

## Нет (намеренно / пока не спутник)

| Возможность | Куда смотреть |
|-------------|---------------|
| Полный рабочий стол | Web / desktop-client (P4, P8) |
| Спутник EWA | Desktop |
| Маркетинговый кабинет / кабинет заказчика | Desktop |
| POEMMA, Professional Worlds | Desktop |
| Site Studio | Desktop |
| Справочник как отдельное нативное app | Desktop / web |

**Не обещаем:** «телефон = полный EliteEW».

Сравнение «хост / DIY / EliteEW» — кратко в [P1](01-what-is-eliteew.md); границы обещаний — [P12](12-honest-limits.md).
