# EliteEW — обзор продукта

Краткий пакет: **что такое EliteEW**, как принять его как открытый дар миру,
и где честные границы. Не runbook и не тарифный лист.

**Языки:** [Русский](00-README.md) · [English](../en/00-README.md)

**Кому:** люди и организации, которым нужен свой рабочий контур · ИТ · ИБ · SI.  
**Модель:** first-party код — дар по `MIT` ([P3c](03c-full-complex-source.md));
сопровождение и hosted — **опция**, исходники остаются открытыми по MIT ([P3e](03e-delivery-models.md)).
