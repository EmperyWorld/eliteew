# P8 — Tauri-клиенты и доверие обновлений

## Тезис

Помимо браузера есть **нативные клиенты** (Tauri) для сценариев Connected / offline-capable / FoFline-adjacent: лаунчер, импорт доступа, защищённый канал, запуск продукта, **подписанные** обновления по доверенному каналу.

| Инвариант | Смысл для организации |
|-----------|----------------------|
| OTA fail-closed | Неподписанное / отозванное обновление не ставится «тихо» |
| Не kiosk / не Trusted Substrate | Клиент на ноутбуке ≠ sealed OS-носитель (P10b) |
| Не путать продукты | Connected и FoFline — разные каналы; не ставить «оба пакета вперемешку» как норму |

**Не обещаем:** «любой exe из интернета доверен» · FoFline = air-gap.
