# P5c — Единый вход и контроль сессий

## Тезис

Вход в рабочий слой — через **корпоративную идентификацию** (OIDC / единый вход организации). Сессия продукта отделена от «просто открыл сайт»; выход и политики доступа задаются контуром заказчика и edition.

Для разных носителей (браузер, мобильный спутник, desktop-client / FoFline) действуют **свои** правила сессии и доверия устройства — детали в P7–P10. Здесь только принцип: **один аккаунт организации → рабочий слой**, без раздачи паролей от десятка SaaS вручную как нормы.

**Не пишем в публичном тексте:** внутренние имена client id, URL IdP, JWT claims.

Сравнение «хост / DIY / EliteEW» — кратко в [P1](01-what-is-eliteew.md); границы обещаний — [P12](12-honest-limits.md).
