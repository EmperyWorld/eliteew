# P3b — Отраслевые профили

**НПА:** отсылка к [P3](03-regulatory-map.md)

## Как читать профили

Это **не** отдельные продукты и **не** аттестаты по отраслям. Это типовые **сборки акцента** одного комплекса EliteEW под крупный масштаб в организация.

| Профиль | Акцент | Типовой состав смысла | НПА-отсылка |
|-----|------|-----|---------|
| Холдинг / много юрлиц | Роли, единый вход, периметр | Стол · роли · Admin-lite · editions | P3 · доступ |
| Маркетинг / агентство | Проекты, заказчик, генерации | Маркетинг-кабинет · Customer Cabinet · файлы · EWRP | P3 · ИИ/ПДн |
| Недвижимость / поле | Профили, объекты, мобильный | Professional Worlds · mobile спутник · звонки | P3 · ПДн |
| Жёсткий периметр / контур персональных данных | Закрытый контур, on-prem | On-prem edition · edge · лицензии · FoFline≠air-gap (P10) | P3 · №60 / 152 |
| Подрядчики / внешние | Ограниченный доступ | Роли · Customer Cabinet · без лишнего Shadow IT | P3 · доступ |
| Демо / live / sealed | Показ без «голого» хоста | Live/sealed (P10b) · любой браузер (P1a) | P3 · контур |
| Госсектор-смежные | Compliance-диалог | Карта P3 + on-prem + роли — **без** «аттестовано» | P3 целиком |

Детали edge, лицензий, editions — в P7d / P9a / P10; здесь только профиль.

Сравнение «хост / DIY / EliteEW» — кратко в [P1](01-what-is-eliteew.md); границы обещаний — [P12](12-honest-limits.md).
