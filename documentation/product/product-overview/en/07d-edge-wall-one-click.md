# P7d — Edge: closed wall and one meaningful access step

**Diagram:** [D06](../assets/diagrams/D06-edge-wall.md)  
**Not in public text:** IPs, ports, interface names

## Thesis

From the outside the contour is **default-deny**: surplus entries for scanners /
casual internet stay closed (a “closed wall”). Work access opens on **issued
trust** (seat / peer / trusted device) — for the person this collapses to **one
meaningful action** (import access / raise a protected channel / bind a device),
not “open ports to the world.”

Phone and desktop-client have **separate** trust contours — not one key for
everything (see P7c / P8 / P9a).

**Not promised:** air-gap · “impossible to breach” · publishing internal topology.
