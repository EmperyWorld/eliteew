# P10a — Native client and hybrid

Delivery is not “browser only” and not “containers only”:

- **Browser** work layer (cloud / on-prem)
- **Native** clients (Connected / FoFline / offline-capable seats) on open server OS and ordinary desktop OS
- Container runtime on the platform side — for services, **not** as the only way a person opens the desk

Hybrid: the host stays yours; EliteEW is a managed layer on top of it ([P1](01-what-is-eliteew.md)).
