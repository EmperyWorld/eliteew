# EliteEW — product overview

A short pack on **what EliteEW is**, how to receive it as a gift to the world
under MIT, and where the honest limits are. Not an ops runbook and not a
service tariff sheet.

**Languages:** [English](00-README.md) · [Русский](../ru/00-README.md)

**Audience:** people and organizations that want their own work contour · IT ·
security · integrators.  
**Model:** first-party code is a gift under `MIT`
([P3c](03c-full-complex-source.md)); hosted runtime and hands-on help are
**optional accompaniment**, never a substitute for the open source grant
([P3e](03e-delivery-models.md)).
