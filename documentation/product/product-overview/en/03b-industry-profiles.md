# P3b — Industry profiles

**Regulation:** see [P3](03-regulatory-map.md)

## How to read profiles

These are **not** separate products and **not** industry attestations. They are
typical **accent assemblies** of one EliteEW complex for large-scale use in an
organization.

| Profile | Accent | Typical meaning set | Regulation pointer |
|---------|--------|---------------------|--------------------|
| Holding / multi-entity | Roles, single sign-on, perimeter | Desk · roles · Admin-lite · editions | P3 · access |
| Marketing / agency | Projects, counterparty, generations | Marketing cabinet · Counterparty cabinet · files · EWRP | P3 · AI / personal data |
| Real estate / field | Profiles, objects, mobile | Professional Worlds · mobile satellite · calls | P3 · personal data |
| Hard perimeter / personal-data contour | Closed contour, on-prem | On-prem edition · edge · entitlements · FoFline≠air-gap (P10) | P3 · local maps |
| Contractors / externals | Limited access | Roles · Counterparty cabinet · less Shadow IT | P3 · access |
| Demo / live / sealed | Show without a “naked” host | Live/sealed (P10b) · any browser (P1a) | P3 · contour |
| Public-sector adjacent | Compliance dialogue | P3 map + on-prem + roles — **without** “attested” | P3 whole |

Edge, entitlements, editions — detail in P7d / P9a / P10; here only the profile.
