# P7 — Android satellite and security

## Thesis

The Android app is a **satellite** of the work contour: feed, messenger, friends,
notifications, profile, some generations, and video calls. It is **not** the full
desk and **not** the marketing cabinet on a phone.

On top of organization sign-in sits an optional **trusted-device** layer (phone
binding): keys are generated on-device; the server never receives private keys.
Without a configured screen lock, trusted binding and GAF E2EE do not enable.
