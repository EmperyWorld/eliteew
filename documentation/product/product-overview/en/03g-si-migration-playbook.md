## Integrator role (self-managed path)

| Zone | Integrator / org IT | Not part of the code license |
|------|---------------------|------------------------------|
| Host / network / backup / monitoring | Yes | Permanent author ops staff |
| IdP, roles, offboarding | Yes (with security) | “Turn on and forget” |
| First edition stand | Yes | Managed prod mistaken for your self-hosted contour |
| Unit pilot | Yes | Automatic managed operations “bundled with the code” |
| Helpdesk L1–L2 | Yes | Vendor desk forever |
| Backlog evolution | Yes (or a contractor) | Someone else’s SaaS roadmap |
| Empery architect | Only a separate arrangement | A guarantee they will “own” the program |

## Migration from a zoo (a program, not a button)

Typical large-organization start: mail/chat outside, disk outside, meetings outside,
AI in personal accounts. EliteEW does **not** promise instant replacement of an
entire host-OS productivity stack.

| Wave | Meaning | Anchor |
|------|---------|--------|
| M0 Shadow IT map | What people actually use (chat/disk/AI) | P2 |
| M1 Day contour | Desk + files + roles for a pilot group | P4 · P4a · P5a · P3a |
| M2 Comms | Internal messenger / meetings instead of work threads outside | P7a · P7b |
| M3 AI | Generations and vault on own materials instead of personal SaaS | P5 · P5b |
| M4 Mobile / edge | Satellite and trust-based access — as needed | P7 · P7d |
| M5 Exit | Policy: work channels only inside the contour | Security + org order; not product magic |

Honestly: a parallel dual-contour period is almost always needed; duration is
Discovery, not a tariff orientation.

## PoC before scale (honest)

PoC goal — confirm real product capabilities, not absolutes from [P12](12-honest-limits.md).

| Check | Expect | Do not expect |
|-------|--------|---------------|
| Agentless / fast access | No admin agent on personal OS as the norm | “Sterile disk always” |
| Pilot-group day | Desk + files + roles work | 1000+ users in a week |
| On-prem / isolated edition | Stand **at you** brought up by SI | Someone else’s shared demo = your contour |
| E2EE chat (if in scope) | Opt-in + key on the phone | All chats always E2EE |
| Atomic native (if Connected/FoFline) | Native-client gate | Same for the whole browser SPA |
| Latency / UX | PoC orientation | Universal ≤200 ms as a promise |
| Regulation | “Helps” map | Information-protection attestation out of the box |
