# P4b — Co-editing documents

## Thesis

The **document editor** supports joint work: who is present, cursors, and
synchronized edits. Joining a shared session is **explicit** (the person turns
on “Connect”) — not a hidden background mode.

Only the **document owner** can invite collaborators. Comments / review live
inside the editor.

## Honest framing

| | |
|--|--|
| **Present** | Co-presence · cursors · sync inside the product editor · owner invites |
| **Not promised** | Feature parity with every external co-editor · co-editing any office binary without conversion |
