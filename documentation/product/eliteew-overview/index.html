Что это

EliteEW — платформа Kernel + Desktop apps, а не набор независимых SaaS. Состав иконок на столе зависит от роли, магазина и install-profile организации. Editions: cloud (hosted), onprem (изолированный контур заказчика), client (устройство / offline-capable + scoped remote tools).

Этот HTML — обзор для людей и для README-контекста репозитория. Операционный SoT (hosts, deploy, stacks) — в PRODUCTION-TOPOLOGY-STATE.md и living product docs под documentation/product/. Partner deck с research-бандлом — ELITEEW-PRODUCT-PRESENTATION.html (другой жанр, не дублировать сюда).
