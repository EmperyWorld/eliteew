# Простые инструкции для пользователей EliteEW

Здесь только то, что нужно **обычному пользователю** рабочего стола: как открыть **Ассистент**, пользоваться **частыми вопросами**, написать в **Обращения**, ориентироваться на столе и в **магазине приложений**. Отдельный файл на каждую тему. Без настроек сервера, без терминов для разработчиков.

| Файл | О чём |
|------|--------|
| [`01-spravochnik-prilozhenie.md`](01-spravochnik-prilozhenie.md) | Приложение **«Ассистент»**: чат, подсказки, отправка вопроса; §«Приложение EliteEW на телефоне» — тот же справочник в MobileAndroid |
| [`02-chastye-voprosy-faq.md`](02-chastye-voprosy-faq.md) | Боковая колонка **«Частые вопросы»** |
| [`03-obrashcheniya-esli-net-otveta.md`](03-obrashcheniya-esli-net-otveta.md) | Приложение **«Обращения»**, если справочника не хватило |
| [`04-rabochiy-stol-vvod.md`](04-rabochiy-stol-vvod.md) | Рабочий стол: Пуск, трей (GAF/UGS/фон; **не** Ассистент/Обращения) |
| [`05-magazin-prilozheniy.md`](05-magazin-prilozheniy.md) | **Магазин приложений**; Ассистент — Пуск/стол, не трей |
| [`06-generator-pesen.md`](06-generator-pesen.md) | **Генератор песен**: мастер и полный режим, текст vs теги звучания, уведомления |

Подсказки на экране и порядок кнопок могут чуть отличаться в вашей версии или языке интерфейса.
