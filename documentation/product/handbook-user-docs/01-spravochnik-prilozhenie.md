# Приложение «Ассистент» на рабочем столе

## Задача приложения

**Ассистент** — окно с чатом и подсказками. Вы задаёте вопросы **о продукте EliteEW** (как пользоваться интерфейсом, где найти раздел, что означает элемент экрана). Ответы опираются на **частые вопросы** и **справочные тексты**, которые ведёт **администратор вашей организации**. Это не поиск по интернету: если нужного материала нет, помощник может извиниться и предложить написать в **«Обращения»**.

## Как открыть

- **Иконка на рабочем столе** — двойной щелчок по «Ассистент».
- **Пуск** — найдите приложение в меню «Пуск» или через поиск на столе.

Отдельного значка в системном трее нет — только окно на рабочем столе (или вкладка в мобильном приложении, см. ниже).

## Как устроено окно

После открытия вы видите:

1. **Шапка** — название «Ассистент», подсказка по теме приложения, счётчик сообщений. Пока готовится ответ — **«Пишу ответ…»**; рядом может появиться строка **«Подбираю по материалам: …»**. На широком экране — кнопки **«Копировать чат»** и **«Скачать чат»**; на узком — **«Обновить историю»** и меню **«⋯»** (копировать, скачать, убрать подсказки из чата, очистить). Кнопка **«Экскурсия»** запускает пошаговый тур.
2. **Слева (на широком экране)** — блок **«Частые вопросы»** с поиском. На узком экране блок **сворачивается**; развернуть — **«Развернуть FAQ · N вопросов»**. Подсказка под шапкой: **«Слева FAQ · справа чат.»** (можно скрыть).
3. **Основная область** — **«Ваши вопросы»** (переписка). У сообщений метки **«Вы»**, **«Ассистент»** или **«Подсказка»** и время. **«Ранние сообщения»** подгружает более старую переписку. **«К новым сообщениям»** прокручивает к последнему ответу.
4. **Поле ввода внизу** — подсказка **«Вопрос про EliteEW…»**, кнопка **«Отправить»**. Под полем: **«Enter — отправить · Shift+Enter — новая строка · Ctrl+. — поле ввода»** и ссылка **«все клавиши»**.

## Частые вопросы: два способа

### На широком экране — колонка слева

Список карточек с поиском **«Поиск по вопросам и ответам…»**. У каждой карточки:

| Действие | Что делает |
|----------|------------|
| Раскрыть стрелкой | Показать готовый ответ администратора **без ожидания** |
| **«Вставить в поле»** / клик по тексту вопроса | Вставить вопрос в поле ввода |
| **«Спросить»** | Отправить вопрос помощнику |
| **«Показать в чате»** | Добавить готовую пару «вопрос — ответ» в переписку сразу |
| **«Копировать вопрос»** / **«Копировать ответ»** | Копирование в буфер |

**/** — фокус в поиск по вопросам. **Escape** в поле поиска — очистить фильтр.

### На узком экране и в пустом чате — chips «Популярные вопросы»

Когда переписка пуста, под заголовком **«С чего начать»** показываются **популярные вопросы** (chips):

- **Клик** — ответ сразу в чате (без ожидания).
- **Shift+клик** — вставить вопрос в поле.
- **Alt+клик** — отправить вопрос помощнику.

На телефоне FAQ по умолчанию **свёрнут** — нажмите **«Развернуть FAQ · N вопросов»**, чтобы открыть полный список как на столе.

Если список пуст (**«Пока нет готовых подсказок — задайте вопрос в поле ниже.»**), пишите свой текст в поле внизу или попросите администратора добавить записи.

## Поле ввода и отправка

- **Enter** или **Ctrl+Enter** — отправить; **Shift+Enter** — новая строка; **Ctrl+.** — фокус в поле; **/** — поиск по вопросам.
- При очень длинном тексте — счётчик символов (лимит ~4000).
- При **слишком частых запросах** — жёлтый баннер **«Подождите N с —»** и подсказка посмотреть готовые ответы слева; кнопка **«Отправить»** показывает обратный отсчёт.
- Во время ответа — **«Остановить»**; после остановки под полем **«Ответ остановлен»**, текст вопроса возвращается в поле.

## Ответы помощника

- **«Помогло»** / **«Не помогло»** (на широком экране полная подпись **«Не помогло — в Обращения»**) — под ответом справочника.
- **«Спросить снова»** — повторить последний вопрос.
- **«Копировать»** у сообщения; **«Копировать код»** у блоков кода.
- В конце ответа может быть блок **«Источники справочника»** — из каких материалов собран ответ.
- Ответы из FAQ в чате помечены **«Подсказка»**; подпись **«Ответ из частых вопросов»**. Можно **«Отправить вопрос»** (уточнить у помощника) или **«FAQ не помог — в Обращения»**.

## Пустой чат

Когда сообщений ещё нет:

- Заголовок **«С чего начать»**.
- Текст: напишите вопрос или выберите подсказку слева; не нашли ответ — **«Открыть Обращения»** или найдите приложение в **Пуске**.
- **Популярные вопросы** (chips) — см. таблицу выше.
- Кнопка **«Открыть Обращения»** открывает форму обратной связи.

Раньше отправленные сообщения подгружаются при открытии. **«Обновить историю»** — принудительно с сервера. При ошибке — **«История недоступна»** и **«Повторить загрузку»**.

## Ограничения

- **Слишком много запросов подряд** — подождите (обратный отсчёт на кнопке). Готовые ответы (**«Показать в чате»**, chips) лимит не расходуют.
- **Вопрос не про EliteEW** — помощник объяснит, что отвечает только по материалам про продукт.
- **Нет ответа в справочнике** — опишите ситуацию в **«Обращения»**.

## Куда обращаться, если справочника мало

1. Переформулировать вопрос короче и по шагам («открыл раздел X → нажал Y → вижу Z»).
2. Заглянуть в **«Частые вопросы»** слева (или развернуть FAQ на телефоне).
3. Открыть **«Обращения»** (см. [`03-obrashcheniya-esli-net-otveta.md`](03-obrashcheniya-esli-net-otveta.md)). Кнопка **«Не помогло — в Обращения»** под ответом подставит ваш вопрос и ответ справочника — останется дописать, что именно нужно.

## Приложение EliteEW на телефоне

В мобильном приложении **EliteEW** (вкладка **EW** → **Ассистент**) тот же справочник внутри приложения.

| На телефоне | Отличие от окна на столе |
|-------------|---------------------------|
| FAQ | По умолчанию **свёрнут**; **«Развернуть FAQ · N вопросов»** |
| Популярные вопросы | **Chips** в пустом чате вместо постоянной левой колонки |
| Переписка | Основная часть экрана |
| Поле ввода | Внизу; **Enter** отправляет (без **Ctrl+.** и блока «Горячие клавиши») |
| Действия | **Обновить историю** и меню **«⋯»** в шапке |

## Краткий чеклист

| Действие | Как |
|----------|-----|
| Открыть приложение | Иконка на столе или **Пуск** |
| Вставить вопрос из FAQ | Клик по тексту / **«Вставить в поле»** |
| Сразу отправить из FAQ | **«Спросить»** |
| Готовый ответ в чате | **«Показать в чате»** или chip в пустом чате |
| Не помогло | **«Не помогло — в Обращения»** |
| Написать команде без ответа | **«Открыть Обращения»** в пустом чате |
| Скопировать переписку | **«Копировать чат»** / **«Скачать чат»** (на узком — в **«⋯»**) |
| Остановить длинный ответ | **«Остановить»** |
| Фокус в поле | **Ctrl+.** |
| Несколько строк | **Shift+Enter** |

Точные формулировки могут слегка отличаться при смене языка интерфейса; логика та же.
