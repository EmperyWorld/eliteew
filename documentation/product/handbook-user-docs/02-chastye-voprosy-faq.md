# Боковая панель «Частые вопросы» в Ассистенте

Раздел **«Частые вопросы»** — это левая колонка (на десктопной вёрстке) или верхняя зона на узком экране в приложении **«Ассистент»**. Над списком стоит подпись **«Частые вопросы»**.

## Что это за список

Каждая строка — **один вопрос** из справочника FAQ, который администратор вашей организации завёл в админ-панели. Ответы помощника в чате строятся с учётом этих записей и отдельных **документов базы знаний** (длинные тексты, файлы — на стороне администратора). Список **не универсальный для всех мира**: набор тем отражает вашу организацию.

## Два действия на каждый вопрос

Интерфейс рассчитан на то, что вы можете и **подправить** вопрос перед отправкой, и **сразу получить ответ**:

1. **Клик по тексту вопроса**  
   Текст **добавляется в поле ввода** внизу окна. Если вы уже что-то написали, новый текст дописывается **с новой строки**. Дальше вы редактируете формулировку и жмёте **«Отправить»** или **Enter**.  
   Подсказка при наведении на вопрос: **«Вставить в поле»**.

2. **Кнопка «Спросить»** (рядом с вопросом)  
   Отправляет **именно этот вопрос** помощнику **без** дополнительного нажатия внизу. Удобно, когда формулировка администратора вас устраивает целиком.

Нет отдельной дублирующей кнопки «Вставить»: сам клик по вопросу и есть вставка в поле.

## Зачем это пользователю

- **Не придумывать формулировку с нуля** — особенно если неясно, как описать типовую ситуацию.
- **Единый язык с поддержкой** — вопросы из FAQ часто совпадают с тем, как команда уже оформила ответы в базе.
- **Быстрый старт** — один клик по **«Спросить»**, если нужен немедленный ответ по готовой теме.

## Если список пуст

Отображается сообщение вроде: **«База подсказок пуста — администратор может добавить записи»**. В этом случае:

- Задавайте вопрос **обычным текстом** в поле внизу (см. [`01-spravochnik-prilozhenie.md`](01-spravochnik-prilozhenie.md)).
- Имеет смысл **сообщить администратору**, что не хватает стартовых вопросов — это ускорит работу всем пользователям.

## Если нужной темы нет в списке

FAQ не заменяет произвольный диалог: пишите запрос **своими словами**. Если одна и та же тема возникает часто, через **«Обращения»** можно передать идею **добавить вопрос в FAQ** (см. [`03-obrashcheniya-esli-net-otveta.md`](03-obrashcheniya-esli-net-otveta.md)).

## Связь с ответом помощника

Нажатие **«Спросить»** не гарантирует «идеальный» ответ: помощник по-прежнему опирается на **всю** настроенную базу (FAQ + документы) и правила тематики **только EliteEW**. Если материалов по теме мало, ответ может быть кратким или помощник честно скажет, что данных недостаточно.

## Сводка

| Ситуация | Что делать |
|----------|------------|
| Нужно слегка изменить формулировку | Клик по вопросу → правка в поле → **Enter** / **«Отправить»** |
| Устраивает готовый текст | **«Спросить»** |
| Список пуст | Писать вручную; напомнить администратору про FAQ |
| Нет нужной темы | Свободный текст в чате или обращение с предложением добавить FAQ |
