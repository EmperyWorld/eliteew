# Ultimate Document Editor — менеджер файлов

Ассистент по боковой панели **«Управление файлами»** в редакторе документов на рабочем столе: сценарии для пользователей, поведение интерфейса и ориентиры для разработчиков и поддержки.

Текст для **базы знаний Ассистента (RAG)** в пользовательской формулировке — [handbook-kb-articles/kb-doc-editor-menedzher-faylov.md](handbook-kb-articles/kb-doc-editor-menedzher-faylov.md); канон продукта «Ассистент» и порядок индексации — [PRODUCT-ASSISTANT-HANDBOOK.md](PRODUCT-ASSISTANT-HANDBOOK.md).

## 1. Где это в продукте

- Панель открывается из редактора документов (кнопка управления файлами в интерфейсе редактора).
- Работает в контексте **desktop shell** (`#desktop-main`): стили на токенах `--desktop-*`, см. теминг выше.
- Список документов приходит с сервера; поиск и пагинация не дублируют весь каталог в памяти браузера.

## 2. Для пользователей (что можно делать)

### 2.1 Общее

- **Новый документ** — создать черновик с названием и открыть его в редакторе.
- **Из библиотеки** — открыть уже загруженный в систему файл как документ (отдельное окно выбора; чанк подгружается при первом использовании).
- **Импорт** — загрузить новый файл с диска (сценарий импорта в продукте).
- **Поиск** — по названию и по извлечённому тексту документов; запрос уходит на сервер с небольшой задержкой после ввода, чтобы не дергать API на каждую букву.
- **Сортировка** — по дате обновления, названию или числу слов; направление (по возрастанию / убыванию) переключается повторным нажатием на тот же критерий.

### 2.2 Недавние и полный список

- Блок **«Недавние»** показывает до трёх документов, с которыми недавно работали в этом браузере (список хранится локально). Он скрывается, если включён **поиск** — чтобы не смешивать «недавнее» с результатами выдачи.
- Ниже — **все документы** (с учётом поиска и сортировки). Документы из блока «Недавние» в общем списке при отсутствии поиска **не дублируются**.

### 2.3 Вид списка

- **Компактный** и **подробный** режимы переключаются кнопкой в шапке панели: в компактном виде на экран помещается больше строк; в подробном — превью текста и дополнительные детали.

### 2.4 Строка документа

- **Открыть** — клик по основной области строки открывает документ и закрывает панель.
- **Выбор** — флажок для пакетных операций (отмеченные документы используются там, где это предусмотрено продуктом).
- **ИИ** — кнопка с иконкой «искр»: отправить документ в контекст помощника **без обязательного открытия в редакторе** (удобно для вопросов по содержимому из списка). Панель файлов при этом закрывается, открывается колонка с ИИ.
- **Удалить** — для документа, который **сейчас не открыт** как текущий; для активного документа пункт удаления скрыт, чтобы не удалить то, что прямо сейчас в работе, одним кликом из списка.

### 2.5 Контекстное меню (правый клик)

По **правому клику** на строку документа (в том числе в блоке «Недавние») открывается меню с теми же смыслами, что и кнопки:

- в шапке меню показывается **название документа** (длинные названия обрезаются, полное имя можно увидеть во всплывающей подсказке, если она поддерживается браузером);
- **Открыть**, **Спросить ИИ**, **Выделить / снять выделение**;
- **Удалить** — только если этот документ не является текущим открытым.

Закрытие меню: клик вне его, клавиша **Escape** (сначала закрывается меню, затем другие диалоги панели — см. ниже).

### 2.6 Догрузка списка

- Если документов больше, чем загружено одной «страницей», доступна кнопка **«Загрузить ещё»** — подтягивается следующая порция с сервера без перезагрузки страницы.

### 2.7 Горячая клавиша Escape

Пока открыта панель файлов, **Escape** обрабатывается в таком порядке:

1. открыто контекстное меню — закрывается меню;
2. открыт диалог создания документа — закрывается диалог;
3. показано подтверждение удаления — снимается подтверждение;
4. иначе — закрывается сама панель менеджера файлов.

### 3.2 Поведение списка и API

- Запросы списка: `listDocuments` в store; на сервере — эндпоинты doc-editor для документов (поиск `search`, пагинация `skip`/`limit`, суммарное число `documentsTotal`).
- Сортировка выполняется **на клиенте** по уже загруженным строкам текущей выборки (как задокументировано в [ULTIMATE-DOC-EDITOR-DESKTOP-THEMING.md](ULTIMATE-DOC-EDITOR-DESKTOP-THEMING.md) для панели файлов).
- Длинные списки: при числе строк **не ниже порога** в коде (`VIRTUAL_LIST_MIN` в `fileManager/fileManagerConstants.ts`) используется `VirtualVariableList`; иначе — обычный список с анимацией появления строк.

### 3.3 Контекстное меню

- Позиция: `getContextMenuPositionFromCursor` из `src/pages/Desktop/utils/desktopUi.ts` (учёт размеров меню и краёв окна).
- Рендер: портал в `document.body`, z-index `DESKTOP_Z_INDEX.CONTEXT_MENU` из `src/pages/Desktop/constants`.
- Шапка меню: компонент `DesktopAppContextMenuTitle` из `DesktopAppChrome` — единообразие с другими ПКМ на рабочем столе.
- Закрытие: `mousedown` на документе (capture), `Escape` в слушателе на `document` внутри компонента меню; панель файлов дополнительно обрабатывает Escape на `window` с приоритетом над закрытием панели.

### 3.4 Локализация

- Пространство имён: `ultimateDocEditor`, ключи панели и меню — префикс `fileManager.*`, контекстное меню — `fileManager.contextMenu.*` в `src/i18n/locales/ru/ultimateDocEditor.json` и `en/ultimateDocEditor.json`.

### 3.5 «Недавние» документы

- Идентификаторы последних открытых документов хранятся в **localStorage** (`doc-recent-documents`), ограничение длины списка задаётся в коде панели.
