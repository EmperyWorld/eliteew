# Fixed Error: Temporal Grounding, Clean Search Queries, and Architecture/LaTeX Render Integrity

**Product:** `kursorina`  
**Date:** 2026-09-07  
**Status:** `fixed`  
**Severity:** `high`

---

## 1. Symptom

1. **Temporal Blindness (2024 Date Hallucinations):**  
   Reports generated by Kursorina included historical training cutoff dates (e.g., «Дата исследования: 15.11.2024» or references to 2024 as the current year) despite running in September 2026. The search queries also used outdated context.
2. **Search Query Pollution & Deduplication Loop:**  
   User goals containing markdown formatting (headers like `##`, bold markers, bullet points) were passed directly to web search engines without stripping formatting, resulting in 0 SERP hits. The LLM repeatedly proposed the same failed query, causing a deduplication loop.
3. **Frontend Render Mutilation (Mermaid & LaTeX):**  
   - Multi-tier system architecture diagrams containing Mermaid `subgraph` clusters were squashed by `parseMermaidFlowchart` into a 1D linear step list, dropping node shapes and inter-cluster connections.
   - LaTeX mathematical expressions (such as `$\rightarrow$`, `$P \times I$`, `$\le$`) were displayed as raw unrendered LaTeX markup in report prose and tables.

---

## 2. Failure Layer

- **LLM Prompting & System Anchoring:** Neither `_DECISION_SYSTEM` nor `_SYNTH_SYSTEM` provided the real-world calendar date or current year context, causing LLM hallucination of training cutoff year 2024.
- **Search Query Tokenization:** Lack of markdown stripping before query formation created malformed SERP queries. Guard deduplication repeated failed facet queries.
- **Frontend / Backend Markdown Normalization:**
  - `parseMermaidFlowchart` did not distinguish linear flowcharts from cluster architecture diagrams with `subgraph`.
  - Lack of LaTeX-to-Unicode symbol normalization.

---

## 3. Root Cause

1. `synthesize.py` and `decide.py` did not inject dynamic calendar context (`current_date_context()`).
2. `_FAKE_META_DATE_RE` indiscriminately stripped date lines rather than correcting them to the current date.
3. `tokenize_goal` and `goal_topic_query` included raw markdown characters (`#`, `*`, `[]()`).
4. `parseMermaidFlowchart.ts` unconditionally treated any `graph` or `flowchart` source as a 1D editorial process flow, flattening complex nested subgraphs.
5. `KursorinaReportMarkdown` and `synthesize.py` did not translate standard LaTeX math notation into clean Unicode equivalents.

---

## 4. Cause-Layer Changes

1. **Backend Temporal Engine (`shared/api/services/kursorina/`):**
   - Added `current_date_context()` in `synthesize.py` returning localized Russian date, ISO format, and current year.
   - Injected dynamic calendar context into `_SYNTH_SYSTEM` and `_DECISION_SYSTEM` prompts.
   - In `decide.py`, pass `current_date` and `current_year` into `llm_decide` user payload.
   - In `polish_product_answer`, deterministic replacement of `202[0-4]` date headers with the current ISO date.
2. **Search Query Cleaning & Deduplication (`plan.py`, `decide.py`):**
   - Added `strip_markdown_decorations()` to clean markdown syntax before tokenization.
   - Added `clean_web_search_query()` to sanitize search queries.
   - In `guard_llm_action`, ensured deduplicated queries alternate to fresh facets or deliverables and never re-issue already executed queries.
3. **Architecture & Math Render Engine (`synthesize.py`, `companionChatMarkdownNormalize.ts`, `parseMermaidFlowchart.ts`):**
   - Implemented `normalize_latex_math_symbols` in Python and TypeScript to map `$\rightarrow$`, `$\times$`, `$\le$`, `$\ge$`, `$P \times I$` to Unicode (`→`, `×`, `≤`, `≥`, `P × I`).
   - In `parseMermaidFlowchart.ts`, return `null` when source contains `subgraph`, allowing `MermaidFenceBlock` to render native Mermaid SVGs.
   - Updated `parseNodeToken` and `parseEdgeLine` regexes to support cylinder database nodes `[(...)]` and bidirectional `<-->` / dotted `-.->` arrows.
