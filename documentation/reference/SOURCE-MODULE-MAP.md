## Separate services, entrances and carriers

- **KBSEW:** [service README](../../KBSEW/README.md), [API](../../KBSEW/api/), [tests](../../KBSEW/tests/). Ingestion drivers include PDF, Markdown, Python and TypeScript; PostgreSQL owns durable job/asset metadata, Qdrant owns vectors, S3 stores source objects. Read/service-token and admin/mutation access differ. Entry: [KBSEW canon](../product/KBSEW.md).
- **Android cloud entrance:** [README](../../pack-cloud/mobile/README.md), [Gradle module registry](../../pack-cloud/mobile/settings.gradle.kts), `app`, `benchmark`, five `core` modules, seven feature modules and `unity-hand-host`. OIDC, Retrofit/OkHttp, local storage and device/platform permissions are owned here. Entry: [Android handbook](../product/mobile/ANDROID-DEVELOPER-HANDBOOK.md).
- **Tauri organization entrance:** [README](../../pack-organization/connection-agent/README.md), [Rust workspace](../../pack-organization/connection-agent/src-tauri/Cargo.toml), native transport/helper crates and React feature UI. Linux RPM and Windows NSIS have platform-specific prerequisites. Signing and channel state are separate from tree version. Entry: [connected client](../product/desktop/DESKTOP-TAURI-CONNECTED-CLIENT.md).
- **Trusted Substrate:** [carrier README](../../pack-organization/trusted-substrate/README.md), [Buildroot configuration](../../pack-organization/trusted-substrate/config/buildroot/), [installer](../../pack-organization/trusted-substrate/installer/README.md), [state-unlock agent](../../pack-organization/trusted-substrate/state-unlock-agent/README.md), Python policies and image scripts. Source recipes do not certify metal acceptance; installation can wipe a disk. Entry: [Trusted Substrate canon](../product/desktop/ELITEEW-TRUSTED-SUBSTRATE.md).
- **Command-center image:** [README](../../pack-organization/command-center-image/README.md), [kickstart](../../pack-organization/command-center-image/kickstart/eliteew-command-center.ks) and preparation/verification scripts. This is build/deploy-host installation media, not an application distribution. The kickstart uses destructive partitioning. Entry: [golden-image guide](../platform/COMMAND-CENTER-GOLDEN-IMAGE.md).
- **Public website:** [Next.js package](../../shared/web/site_prod/README.md), App Router pages, `/health`, `/api/lead`, typed content and JSONL lead storage with optional webhook. It is separate from user-created Site Studio sites. Entry: [landing guide](../product/SITE-PROD-LANDING.md).
- **Retained static landing:** [shared/web/landing](../../shared/web/landing/README.md) contains an independent static content/build package. Its historical deployment prose requires review; it must not be treated as proof that this package is the currently deployed Next.js site.
- **Olenti and runtime profiles:** [template README](../../site-templates/olenti/README.md), combined public/admin and storefront build entries, Express routes, Prisma schema and [profile JSON](../../site-templates/runtime-profiles/README.md). JWT/PostgreSQL configuration is separate from the shared FastAPI settings. No complete dev stack should be inferred from its legacy compose file.
- **Worker sidecars:** [rendering app](../../shared/api/services/rendering/render_sidecar_app.py) exposes HTML slide screenshots; [science app](../../shared/api/services/science_stack/science_sidecar_app.py) exposes semantic analysis/WAV merge. [Queue-worker startup](../../docker/builders/stack0-api/scripts/start_queue_worker.sh) starts them conditionally. They are not public main-API routers.

## Infrastructure, assets and tooling

- [docker](../../docker/): stack manifests, image builders, nginx/host configuration and deploy/config-plane scripts. The directory name does not require Docker Engine. See [infrastructure guide](../platform/INFRASTRUCTURE-SOURCE-GUIDE.md).
- [host](../../host/README.md): workflow JSON, offline policy, operational assets and systemd host tooling. Ignored runtime/generated directories are not source-code packages.
- [scripts](../../scripts/README.md): profile validation, releases, backup and operator wrappers. Scripts can mutate data or hosts; `--help` availability does not imply every command is safe to run.
- [tools](../../tools/README.md): architecture guard, repository-policy checks and [KBSEW MCP](../../tools/eliteew-kbsew-mcp/README.md), which exposes five read-oriented tools over KBSEW HTTP.
- [documentation](../README.md): living domain references, user/product articles, localized overview exports and historical records. Export duplicates and test fixtures are not independent runtime modules.
- `.cursor/` and `.githooks/`: agent/development governance. They are inventoried but are not product services. A broken recipe-index documentation link was corrected; their policy/configuration was not changed.
